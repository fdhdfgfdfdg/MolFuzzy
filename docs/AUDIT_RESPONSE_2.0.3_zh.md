# MolFuzzy 2.0.3 逐项修正说明

1. JSON 导出：递归转换 NumPy 数组、零维数组和 longdouble 标量；转为 binary64 时发生溢出或非有限值则明确拒绝。扩展精度会舍入，未承诺无损保存。
2. 失败扰动：计算前保存单元索引、专家位置标签、准则/备选项标签、原值、新值和变更后输入 SHA-256；失败记录另含异常类型和原因。测试使用注入故障，不表示默认案例自然失败。
3. 参数网格：两类扫描新增 on_error="record"，逐项记录预期错误后继续。默认 on_error="raise" 保持列表返回及遇错终止。记录模式给出请求、成功、失败和未执行数，包含失败时全量稳定性为 None；单因素扫描计数包含基线，基线错误仍抛出。
4. ACO：共用验证器，在遍历关闭时也校验全部选项；配置导出规范化的参数及 completed/disabled 执行状态。
