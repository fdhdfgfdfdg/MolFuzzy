# MolFuzzy 2.0.6 逐项修正

1. 可靠性维度：内部 beta 加权结果采用有界舍入处理。全部维度为 1 的合法边界案例及完整管线通过；外部负值和大于 1 的值仍被拒绝。
2. 共识性能：每轮以数组批量处理有界校正、归一化和残差，仅最终构造 MFV。随机矩阵与逐对象参考递推逐元素一致，返回矩阵与报告残差完全对应。
3. 发布完整性：递归比较源码、wheel、sdist 的 Python 模块集合，再比较内容；拒绝缺失、多余、重复模块。测试包含源码缺失、源码新增、wheel 新增、sdist 缺失和嵌套新增文件。

新增 16 项回归用例，共 205 项。测试、安装验证、数值复现和性能记录保存在 validation 目录。Windows/macOS 的 CI 配置不代表已实测。历史审计文档仅记录对应旧版本。

验证完成：源码205项通过；Linux/Python3.12.14 + NumPy2.5.4、Linux/Python3.9.25 + NumPy1.24.0 的独立已安装wheel环境各205项通过，外部目录CLI JSON检查通过。共识同机基准中位数由89.57ms降至5.59ms，约16倍；默认完整流程中位数9.06ms，原始样本见日志。
