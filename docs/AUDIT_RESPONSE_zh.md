## 本机实际验证

- Python 3.12、NumPy 2.3.5、Linux；68项测试通过。
- Wheel成功构建；在单独venv中安装，从源码目录外运行CLI成功。venv复用系统NumPy，因此不等于完全隔离的依赖解析测试。
- 15组几何/松弛步长运行完成。结果恒等有代数原因，不能称为15个独立模型的外部验证。
- 100次随机单元格相邻等级扰动：SMRT第一100次；完整排名保持80次。
- 3次逐专家删除：第一第二位保持，但部分后续名次改变。
- 强制启发式ACO、100种子：77次达到精确最优代价，4种路径；这属于路径分析，不影响独立效用排名。
- 默认效用排名：SMRT > SCH > AI > MNT > JTM。
- 默认精确访问序列：JTM -> SCH -> MNT -> SMRT -> AI。

## 方法变化及保留限制

1. 本版本不是原方法的忠实数值复现。其优劣排名方法已明确改为可解释的加权效用，保留路径功能但不混淆语义。
2. 加权共识可直接解析计算，迭代仅用于诊断；学习率影响速度而不影响最终分数。
3. 默认可靠性衡量面板一致程度，不能证明专家正确；相似网络不证明因果关系。
4. 语言尺度、可补偿性、角度正则阈值及hesitancy没有独立效用惩罚，均是需要应用领域论证的假设。
5. 原始案例矩阵来自上传v1分发包，未独立证实其真实采集来源；文稿已定位为示例数据。
6. 未执行Windows/macOS/全部Python版本CI，也未将可选pymcdm比较称为算法交叉验证。
