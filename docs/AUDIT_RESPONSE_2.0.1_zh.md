# MolFuzzy 2.0.1 逐项修复说明

| 审计项 | 修复 | 验证 |
|---|---|---|
| 输入文件被输出覆盖 | 检查真实路径与同文件关系；禁止输入覆盖；其他已有输出需 --force；临时文件原子发布 | 同路径、相对路径、软硬链接，各测试有/无 --force；提交失败时原文件不变 |
| 几何注册污染 | 禁止重复名称注册；原始角度独立计算 | 五种内置名称不可覆盖，自定义尺度不改变 NR |
| 显式权重被网络收敛阻断 | 仅自动权重模式强制网络收敛；保留诊断状态 | 单次网络迭代下用户权重得分可用，自动模式仍报错 |
| 极小阈值溢出 | 列缩放倒数；angle_floor 下限 sqrt(float64.tiny)，独立倒数下限 float64.tiny | 下限边界、极大阈值、重复向量、精确/启发式遍历与非法阈值 |
| 复数截断、布尔权重 | 浮点转换前检查实数类型；推广至可靠性和数值矩阵接口 | 复数、布尔、字符串、object 数组输入拒绝 |
| 容器不一致 | 标签标准化，枚举索引，扰动前构造可变矩阵 | NumPy 标签与列表结果一致，嵌套元组扰动结果一致 |
| 配置外部引用 | 深复制构造参数和结果配置，复制标签 | 调用方修改权重、类型、可靠性维度和结果快照不改变原对象 |
| wheel 验证不足 | 独立环境安装，在源码目录外运行全部测试与 CLI | validation/current-wheel-tests.txt 与 lower-wheel-tests.txt |
| 敏感性证据不足 | 8组准则权重、6组专家权重、6组阈值，保留得分间隔与分组 | validation/results.json；不是置信区间或跨领域有效性证明 |

新增37项回归测试；原68项保持通过，共105项。版本断言随发布号更新，原有数学性质测试保留。
