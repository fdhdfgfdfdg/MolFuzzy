# MolFuzzy 2.0.4 逐条修正

1. 内部加权聚合和评分增加有界舍入修正：容差 min(1e-8, 8*n*float64.eps)。超过容差或非有限值仍报错，外部 MFV 输入范围不放宽。纯隶属、纯非隶属、纯犹豫及随机凸组合均覆盖。
2. 记录模式扫描报告在返回前递归转换为原生 JSON 类型，覆盖成功、失败及扩展精度参数，严格 json.dumps(..., allow_nan=False) 可直接运行。
3. 相邻分差按原始得分降序计算，并输出顺序和配对标签；并列组之间的分差单独定义为上一组最低分减下一组最高分，只有一个组时为空。显示字母顺序不再决定分差。

新增 23 项回归测试，共 181 项。源码、Linux/Python 3.12 + NumPy 2.5.4 和 Linux/Python 3.9 + NumPy 1.24.0 的隔离已安装 wheel 验证均通过，CLI JSON 检查通过。完整数值复现与三图重生成，计时随本次运行更新。Windows/macOS 尚未实际运行；不把 CI 配置当作测试通过证据。

文稿同步更新数值边界、JSON 返回契约、并列分差定义和验证证据。作者、资助、利益冲突、公开仓库及 DOI 仍需补充确认。
